# 实验协议

## 数据划分

1. 源域训练/验证按设备或完整记录划分，然后切窗。相邻重叠窗口不能跨集合。
2. 目标域正常支持集拆成 target_normal（适配和建立锚点）与 target_calibration（轮次选择、分数阈值）。
3. target_unlabeled 可含正常与异常，但适配脚本不读取标签字段。它不能包含测试记录或与测试记录重叠的窗口。
4. target_test 只在最终评估时读取标签。按校准集的正常分位数确定阈值，报告 ROC-AUC、Average Precision、校准阈值 F1、测试正常误报率。

## 必做基线与消融

- 仅源域正常重建；
- 源域正常重建 + 域对抗；
- 源域完整模型（异常解码器训练期对抗）；
- 完整模型 + 目标域正常支持适配；
- 完整模型 + 目标域正常支持适配 + 无标签伪正常选择；
- 分数消融：重建误差、掩码不确定性、正常锚点距离、尺度偏离及组合。

所有方案在同一窗口划分、同一目标域正常支持量、同一校准集和同一随机种子集合下比较。至少报告 5 个随机种子的均值和标准差。对跨数据集结论，逐个目标域报告，不用合并窗口的单一分数替代。

## 当前实现的范围

这次仓库初始化实现了端到端最小流水线和合成数据冒烟验证。正式结果尚未产生。真实数据还需整理成统一 npy 窗口并编写来源/设备级数据清单；目前的知识图谱仅为占位示例。实验应在真实数据和充分训练下重新验证。
