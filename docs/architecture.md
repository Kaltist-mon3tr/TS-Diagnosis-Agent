# 模型结构与损失定义

## 总体数据流

原始多通道窗口 x∈R^(C×T) 经逐通道形态标准化后进入共享卷积编码器。原始窗口尺度另行保留，作为部署证据，避免标准化擦除幅值异常。

x → Eθ → (zs, zp)

- zs：跨域共享表征，接正常解码器，并通过梯度反转的域分类器学习域不变信息；
- zp：域特定表征，通过普通域分类损失保留域差异；
- Dn：正常解码器，在源域正常窗口上训练重建；
- Da：异常解码器，仅在源域训练期作用于异常窗口；解码器自身最小化异常重建误差，共享编码器通过梯度反转最大化该误差。它用于塑造共享表征，不会被部署评分调用；
- Aφ：目标域仿射适配器，初始化为恒等映射，阶段二只更新该模块。

编码器对通道共享卷积核，先分别处理各通道，再聚合通道维度的全局嵌入。不同样本的窗口长度和通道数可以不同，但同一批次形状必须一致。

## 阶段一目标

正常重建只对正常样本计算，异常重建只对异常样本计算。令 y=0 为正常，y=1 为异常，则核心目标为：

L = Ln(Dn(zs),x | y=0)
  + λa La(Da(GRL(zs)),x | y=1)
  + λs Ld(Cs(GRL(zs)),d)
  + λp Ld(Cp(zp),d)
  + λo Lorth(zs,zp).

梯度反转只改变回到共享编码器的梯度方向：异常解码器仍然学习重建异常样本；共享编码器则被推动为减少异常可重建信息。共享域分类器推动 zs 减少域可辨性，私有域分类器保留 zp 的域相关信息。该设计需要通过消融验证，不预设它必然提升目标域检测。

## 阶段二目标域适配

把目标域正常支持集拆成适配集 Na 与独立校准集 Nc。混合无标签池 U 不读标签。先用未适配模型和 Na 正常锚点对 U 打分，再选取低分分位数作为伪正常候选。适配时冻结编码器、两个解码器和域判别器，仅训练 Aφ：

minφ Ln(Dn(Aφ(Eθ(x))),x) + λc Lconsistency + λr Lanchor, 其中 x∈Na∪Upseudo。

Nc 不参与梯度更新，只用于挑选适配轮次和标定部署误报阈值。测试标签只在最终评估时读取。

## 部署评分

部署路径只运行共享编码器和正常解码器。对多个固定掩码 mj 求重建误差 ej，并组合：

S(x)=0.45 ẽ0 + 0.15 Std~(ej) + 0.15 d̃(zs,Bt) + 0.25 Δ~scale(x)。

各项用目标域正常支持集的稳健尺度归一化。系数只是可运行的初始配置，正式实验应在预先划分的校准集上选定并冻结。阈值由独立目标正常校准集的分位数确定，不从测试集寻找最佳阈值。

异常解码器不会输出分数、不会参与分数融合，也不会被诊断脚本加载调用。它对部署行为的影响仅来自阶段一学到的编码器权重。

## 结构化证据与知识辅助报告

证据记录目前包含异常分数及分量、基于正常解码器残差的候选片段、RMS/标准差/峰值/峰值因子、主频位置和运行工况。知识图谱只返回候选原因与维护动作，报告生成器需要把结论映射到这些证据字段；证据不足时应输出“需复核”。knowledge/graph.json 是演示知识，不是权威标准或真实专家知识，必须替换为有出处的领域知识。

当前阶段没有真实 LLM 权重微调，也不需要微调才能跑通链路。脚本提供可选本地 Ollama 接口；没有本地模型时会输出可审计 JSON 诊断输入。
